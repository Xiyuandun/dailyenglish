# DailyEnglish · 每日英语精进 — 项目总览

> 本文档基于项目的真实代码与 git 历史整理，作为完整项目的权威说明。
> 共 4 份文档：`01-项目总览`、`02-语音与语音识别方案`、`03-学习模块详解`、`04-部署方式与开发历史`。

## 一、这个项目是什么

一个**纯前端的每日英语学习网页**（"DailyEnglish · 每日英语精进"），目标人群是英语四级学习者。核心设计是"每天 30 分钟，三月（90 天）精进"，但实际采用 **30 天一个内容周期**的轮换机制。

它包含 5 个页面模块：

| 模块 | Tab | 作用 |
|------|-----|------|
| 今日总览 | home | 今日打卡、连续天数、三项任务进度、三月目标 |
| 单词训练 | words | 每天学习新词 → 小测验 → 完成页可下载 PDF 单词表 |
| 场景对话 | dialogue | 真实场景（点餐/就诊/打车等）逐句录音朗读与点评 |
| 文章阅读 | reading | 单篇文章、段落朗读/慢速、短语与语法讲解 |
| 学习报告 | report | 词汇掌握率、发音练习次数、写作平均分、本周进度 |

## 二、技术栈

- **纯前端**：`HTML + Tailwind CSS（CDN）+ 原生 JavaScript`，无任何前端框架。
- **数据存储**：浏览器 `localStorage`（见 `js/store.js`），支持多用户学习码隔离。
- **语音生成**：`edge-tts`（微软神经网络语音，Jenny 等自然音色）——**可选后端**，详情见 02 文档。
- **语音识别**：多方案（浏览器 Web Speech / Vosk 离线模型 / 阿里云 DashScope Paraformer），详情见 02 文档。
- **可选 Python 后端**：`server.py`（静态服务 + TTS + STT）、`proxy_connect.py`、`tunnel.py`。

## 四、模块加载顺序（index.html 底部）

脚本顺序**有严格依赖要求**，不可随意打乱：

```html
data/scenarios.js → data/article.js → data/audio.js → js/store.js
→ data/days.js → js/daycycle.js → js/speech.js
→ js/words.js → js/dialogue.js → js/reading.js → js/report.js
→ js/app.js
```

- `store.js` 先于 `daycycle.js`（applyNewDay 依赖 Store）。
- `daycycle.js` 先于各学习模块（它把 `DAILY_WORDS` / `DAILY_SCENARIOS` / `DAILY_ARTICLE` 赋为当天内容）。
- 每个文件都带 `?v=版本号` 缓存参数，改动后需递增，否则浏览器用旧缓存。

## 五、本地运行方式

**方式 A：纯静态预览（最简单）**
```bash
cd dailyenglish
python3 -m http.server 8000
# 打开 http://localhost:8000/
```

**方式 B：带语音/识别的完整后端**
```bash
cd dailyenglish
pip install -r requirements.txt        # 仅需 edge-tts 等
# 需要语音识别时才必须配：export DASHSCOPE_API_KEY=xxx
python3 server.py 8000                 # 静态 + /tts + /stt
```

## 六、环境检测与自适应

`speech.js` 的 `init()` 会根据 `location.hostname` 判断运行环境：

- `localhost / 127.0.0.1 / lhr.life`（本地）→ 启用云端 TTS。
- `onrender.com`（Render 后端）→ 启用云端 TTS。
- **其他（GitHub Pages / Vercel 纯静态）**→ 禁用云端 TTS，改用静态音频 + 浏览器内置语音 / 有道 TTS。

这也是"无后端也能有自然声音"的关键：依赖**预生成的静态 MP3**（见 02 文档）。

# DailyEnglish · 学习模块详解

## 一、共享基础设施

### Store（js/store.js）— 本地状态管理

- 用浏览器 `localStorage`，key 为 `dailyenglish_state_v1[_用户码]`。
- **学习码隔离**：输入不同学习码，各使用者进度独立保存；未登录用公共 key。
- 存储字段：`points`（积分）、`streak`+`lastCheckin`（连击）、`weekHistory`（周榜单）、`tasks`（今日三项任务完成位）、`wordIndex/wordQuizDone/wordCorrect`（单词进度）、`pronCount`（发音次数）、`writeScores`（写作历史）、`lastDay`（跨天重置依据）、`dark`（主题）、`voice`（音色）。
- `applyNewDay(dayIndex)`：跨天后**只**清零每日任务标记和单词进度，保留积分/连击/周历史等长期数据。
- `checkin()`：一天限打一次，计算连击，+10 分，写入周历史。
- `recordTask(type)`：完成一项任务 +20 分。

### DayCycle（js/daycycle.js）— 30 天内容轮换

- 基准日 `EPOCH='2026-09-01'`，周期 `CYCLE=30`。
- `todayIndex()`：取「今天-基准日」天数 mod 30，得到当天索引。
- `bootstrap()`：把 `DAY_PLAN[当天]` 的 words/scenarios/article 赋给 `DAILY_WORDS / DAILY_SCENARIOS / DAILY_ARTICLE`，并调用 `Store.applyNewDay()` 处理跨天重置。
- **任何模块都只读 `window.DAILY_*` 全局变量**，自己不关心"今天是第几天"，从而零耦合。

### app.js — 主控制器

- `switchTab(name)`：切模块前统一停止朗读/录音/回放；按需 `init()` 对应模块。
- 负责：主题切换、学习码输入、语音下拉框、今日打卡按钮、周打卡点、进入页面时 `Speech.stop()` 兜底（beforeunload/pagehide/visibilitychange）。

## 二、单词训练（js/words.js）

流程：**学习卡片 → 小测验（6 题）→ 完成页（可下载 PDF）**。

### 学习卡片
- 显示：单词、音标、释义、例句（中英）。
- 按钮：🔊 朗读、🐢 慢速（`Speech.speak(word, 0.6)`）、🎤 录音跟读、▶ 回放录音。
- 录音跟读：调 `Input.startRecognition('en-US')`，识别结果用 `Speech.scorePron(text, word)` 打分（0–100），按 85/60 分档显示「优秀/不错/需练习」，并累计 `pronCount`。
- 有明文错误提示：浏览器不支持 → 提示用 Chrome/Edge；非 HTTPS → 提示需 https。

### 小测验（6 题，随机抽词）
题型按 `quizIdx % 3` 循环（`total=6`）：
1. **听音辨词**（type 0）：🔊 播放后从 4 个单词选听到的（`randomOthers` 造干扰项）。
2. **中文填空**（type 1）：给中文意思，输入对应英文单词。
3. **发音评分**（type 2）：朗读指定单词，系统打分。

`score` 正确计数 → 完成页显示掌握数 `wordCorrect/total`，可**下载今日单词表 PDF**（`downloadPdf`）。

## 三、场景对话（js/dialogue.js）

两步走：**第一页逐句录音 → 第二页整段英文翻译**。

### 第一页（中文 + 逐句录音）
- 顶部情境提示 `situationZh`，上下切换场景、可重新开始。
- 每句一人一条气泡：先给**中文**，每句有独立 🎤 录音按钮（每句单独录一段，重录可覆盖）。
- 录完点击「翻页 → 查看英文翻译」进入第二页。
- 逐步录音挑战：扮演两个角色，一句一句说，`updateOverall()` 显示整体进度。

### 第二页（英文翻译 + 语言解析）
- 每句显示英文 + 中文，单句 🔊 朗读。
- 底部「💡 语言解析」列出该场景 `tips`（实用表达/语法提示）。
- 提供「🔊 朗读整段对话」「⏹ 停止」「← 返回录音页」。
- 进入第二页时 `Speech.prefetch(全部英文句)` 预缓存，点击即可秒播。

## 四、文章阅读（js/reading.js）

- 开篇 `Speech.prefetch(所有段落常速)` + 可用「🔊 全文朗读」「🐢 慢速」。
- 段落展示：英文（点击/🔊 单句朗读）+ 中文翻译对照。
- 配套「短语积累（= 释义）」和「语法讲解」区块。
- 数据由 `DAILY_ARTICLE` 提供：`{title, titleZh, paragraphs:[{en,zh}], phrases:[{phrase,meaning}], grammar:[{point,explain}], tips:[]}`。

## 五、学习报告（js/report.js）

纯展示，读 `Store.get()`：
- 词汇掌握率：`wordQuizDone ? wordCorrect/20 : 0`。
- 发音练习次数：`pronCount`。
- 写作平均分：`writeScores` 平均（历史功能，当前单词模块无写作）。
- 本周进度条：读取 `weekHistory` 中连续 7 天的每日三项任务完成数（0–3）。

## 六、数据文件（data/）

| 文件 | 内容 |
|------|------|
| `days.js` | **`window.DAY_PLAN`**：30 天完整内容，每天含 `words` / `scenarios` / `article`。这是主数据源（4.2k 行）。 |
| `words.js` / `scenarios.js` / `article.js` | 兜底用（无 DAY_PLAN 时的旧静态全局）。 |
| `audio.js` | **`window.STATIC_AUDIO`**：预生成静态音频清单，`{meta, normal, slow}`。 |

> 每日数据格式（days.js 中每天对象）：
> `day = { words: [ {word, phonetic, meaning, example, exampleZh} ], scenarios: [ {scene, roles:{user,clerk}, situationZh, turns:[{role:'user'|'clerk', zh, en}], tips:[]} ], article: {…} }`
